ANTES DE COMEÇAR: APRENDER AS BASIAS
Compreender sua tela de computador
Quando você ligar seu computador, você verá uma tela que se parece com uma área de trabalho. Isto chama-se DESKTOP.

O BARRO DE Tarefas (Botão de tela)
No fundo da tela, você verá uma barra horizontal. Isto chama-se barra de tarefas.

No Windows 11:

A barra de tarefas está na parte inferior
No meio da barra de tarefas, você verá um logotipo do Windows (parece quatro quadrados)
Este é o BUTTON START
À direita do botão Iniciar, você pode ver ícones para programas (como um navegador web)
Na extrema direita, você verá a hora e a data
No Windows 10:

A barra de tarefas está na parte inferior
No lado esquerdo da barra de tarefas, você verá um logotipo do Windows (quatro quadrados)
Este é o BUTTON START
Ao lado dele está um ícone de busca (parece uma lupa)
O resto da barra de tarefas mostra os ícones do programa
Na extrema direita, você verá a hora e a data
O botão de arranque, onde está?
Para Windows 11:

Olhe para o fundo do seu ecrã
Olhe no meio da barra inferior
Você verá um logotipo do Windows (4 quadrados dispostos em uma grade 2x2)
Este é o BUTTON START
Para clicar nele, mova o cursor do mouse para ele e clique no botão esquerdo do mouse uma vez
Para Windows 10:

Olhe para o canto inferior esquerdo do seu ecrã
Você verá um logotipo do Windows (4 quadrados)
Este é o BUTTON START
Para clicar nele, mova o mouse para ele e clique no botão esquerdo do mouse uma vez
O que acontece quando se bate o botão de arranque?
Quando você clicar no botão Iniciar, um menu aparecerá mostrando:

Uma caixa de pesquisa no topo
Vários ícones e programas de aplicativos
Um botão de energia na parte inferior (para desligar/ reiniciar)
Usando o bigode
O mouse é o dispositivo na sua mão que você usa para controlar o cursor (seta) na tela.

Movendo o mouse: Mova o mouse em sua mesa para mover a seta na tela
Botão esquerdo: Pressione o botão esquerdo do mouse uma vez
Botão direito: Pressione o botão direito do mouse uma vez
Clique duas vezes: Pressione o botão esquerdo duas vezes rapidamente
UTILIZANDO O CHAVE
O teclado é o dispositivo com letras e números que você usa para digitar.

Pressionando uma tecla: Empurre para baixo uma tecla e solte-a
Segurando uma chave: Empurre para baixo uma chave e mantenha-a segura enquanto faz outra coisa
Tipo: Pressione as teclas uma de cada vez para inserir o texto
SECÇÃO 1: PROBLEMAS DE CONEXÃO INTERNET & REDE
Problema #1: Nenhuma conexão à Internet (O computador diz "Sem Internet")
O que isso significa: Seu computador está conectado a Wi-Fi ou ethernet, mas não pode acessar a internet.

Fixação rápida # 1: Verifique se o Wi-Fi está ligado
Passo 1: Olhe para a tela

Olhe para o canto muito inferior direito do seu ecrã
Você verá vários ícones pequenos (isso é chamado de bandeja do sistema)
Um destes ícones deve parecer barras de sinal Wi-Fi (parece linhas curvas) ou um ícone de cabo de rede
Passo 2: Clique no ícone de rede

Mova o cursor do mouse para o ícone Wi-Fi ou rede
Clique nele uma vez com o botão esquerdo do mouse
Um menu pequeno aparecerá mostrando redes disponíveis
Passo 3: Verifique se o Wi-Fi está ligado

Neste menu, você deve ver seu nome de rede listado
Abaixo do nome da rede, deve dizer "Conectado"
Se diz outra coisa, ou se você não vê sua rede, continue para o próximo passo
Passo 4: Ligue o Wi-Fi se estiver desligado

No menu de rede, procure uma opção Wi-Fi (um botão que pode estar ligado ou desligado)
Se estiver OFF (aparece cinza), clique uma vez para ligá-lo
Espere alguns segundos.
Passo 5: Conecte-se à sua rede

Veja a lista de redes disponíveis
Encontre o seu nome de rede (geralmente algo como "Linksys" ou o nome do seu provedor de internet)
Clique nele
Uma caixa aparecerá pedindo sua senha Wi-Fi
Digite sua senha exatamente (tenha cuidado com letras maiúsculas e minúsculas)
Clique no botão "Conectar"
Espere 10-20 segundos.
Tente usar a internet (abra um navegador e vá para um site)
Fixação rápida #2: Verificar o modo do avião
Modo de avião é uma configuração que desliga todas as conexões sem fio. Se estiver ligado, não podes usar o Wi-Fi.

Passo 1: Abrir configurações

Olhe para o centro inferior esquerdo ou inferior do seu ecrã
Encontrar o logotipo do Windows (4 quadrados) - este é o START BUTTON
Clique nele uma vez com o botão esquerdo do mouse
Um menu aparecerá
Passo 2: Clique em Configurações

No menu que apareceu, procure um ícone de engrenagem ()
Esta é a aplicação Configuração
Clique nele uma vez com o botão esquerdo do mouse
Uma nova janela será aberta
Passo 3: Encontrar rede e Internet

Na janela Configurações, olhe para o lado esquerdo
Você verá uma lista de opções
Encontrar e clicar em "Rede e Internet"
O lado direito da janela irá mudar para mostrar as opções de rede
Passo 4: Verificar o modo de avião

No lado direito, procure "Modo de avião"
Você verá um botão de comutação (parece um interruptor que pode ser ligado ou desligado)
Se mostrar ON (o interruptor é azul ou realçado), clique nele para desligá-lo
Espere alguns segundos.
Verifique se você pode agora acessar a internet
QUICK FIX # 3: Reinicie seu modem e roteador
Seu modem = O dispositivo fornecido pela sua empresa de internet. Normalmente tem luzes piscando e senta-se em um armário ou em uma prateleira.

Seu roteador = O dispositivo que envia sinal Wi-Fi. Às vezes é construído no modem, às vezes é separado.

Importante: Isto irá desconectar temporariamente todos usando o Wi-Fi. Certifique-se de dizer a outras pessoas em sua casa.

Passo 1: Encontre seu modem e roteador

Olhe em volta de sua casa para o(s) dispositivo(s) com luzes piscando
O modem geralmente tem um cabo de internet conectado a ele
O roteador (se separado) geralmente tem antenas
Passo 2: Desligue o modem

Encontrar o cabo de alimentação ligado ao modem
Siga-o até à tomada de energia (a tomada de parede)
Puxe suavemente a ficha de alimentação da tomada de parede
As luzes no modem vão parar de piscar e desligar
Passo 3: Espere 30 segundos

Conte devagar, um mil, dois mil, trinta mil.
Isto dá ao modem tempo para desligar completamente
Passo 4: Conecte o modem de volta em

Empurre o plugue de energia de volta para a tomada de parede
As luzes no modem começarão a piscar novamente
Aguarde 2-3 minutos para todas as luzes pararem de piscar (isto significa que o modem está totalmente reiniciado)
Passo 5: Desligue o roteador (se tiver um separado)

Se você tiver um roteador separado (um dispositivo diferente com antenas), encontre seu cabo de alimentação
Puxe suavemente a ficha de alimentação da tomada de parede
As luzes apagarão
Passo 6: Espere 30 segundos

Contar lentamente novamente: um-um-milhares, dois-um-milhares... trinta-um-milhares
Passo 7: Conecte o roteador de volta para dentro

Empurre o plugue de energia de volta para a tomada de parede
Espere 2-3 minutos para as luzes pararem de piscar
Passo 8: Teste sua internet

Abra um navegador web (como Chrome, Firefox ou Edge)
Ir para um site (como google.com)
Veja se carrega
FIX RÁPIDO #4: Esqueça e reconecte-se à sua rede Wi-Fi
Às vezes, seu computador "lembra" informações incorretas de Wi-Fi. Esquecer a rede e reconectar pode consertar isso.

Passo 1: Abrir configurações

Clique no botão START (logótipo do Windows no fundo da tela)
Procure o ícone da engrenagem (ou) no menu
Clique para abrir Configurações
Passo 2: Ir para rede e Internet

Na janela Configurações, olhe para o lado esquerdo
Clique em "Rede e Internet"
Passo 3: Clique em Wi-Fi

Do lado esquerdo, devias ver "Wi-Fi"
Clique em
Passo 4: Clique em Gerenciar redes conhecidas

No lado direito, você verá várias opções
Procure "Gerenciar redes conhecidas" ou "Gerenciar redes Wi-Fi"
Clique em
Passo 5: Encontre sua rede

Você verá uma lista de redes que você já conectou antes
Encontre seu nome de rede na lista
Clique nele para selecioná-lo
Passo 6: Esqueça a rede

Um botão deve aparecer que diz "Esquecer"
Clique no botão "Esquecer"
Seu computador vai esquecer esta rede
Passo 7: Reconectar à rede

Voltar para o menu de rede
Clique no ícone Wi-Fi no canto inferior direito da tela novamente
Encontre seu nome de rede na lista
Clique nele
Passo 8: Digite sua senha

Uma caixa aparecerá pedindo sua senha Wi-Fi
Digite sua senha exatamente (superior e minúscula)
Clique em "Next" ou "Conectar"
Espere 10-20 segundos.
Tente usar a internet
QUICK FIX #5: Reiniciar configurações de rede (Avançado - Só se acima não funcionar)
ATENÇÃO: Isso é mais técnico. Só tente se as correções acima não funcionou.

O que estás prestes a fazer: Você usará o Prompt de Comando para enviar comandos especiais para o Windows para redefinir suas configurações de rede.

Passo 1: Abrir Prompt de Comando como Administrador

Clique no botão START (logótipo do Windows na parte inferior)
Um menu aparecerá
Digite as palavras: "prompt de comando" (use seu teclado para digitar estas letras)
Você verá "Prompt de Comando" aparecer nos resultados da pesquisa
Botão direito do mouse em "Prompt de Comando" (clique com o botão direito do mouse)
Um menu menor aparecerá
Clique em "Execute como administrador"
Uma caixa pode aparecer perguntando "Você quer permitir que este aplicativo faça alterações?" - Clique em "Sim"
Passo 2: Digite o primeiro comando

Agora você verá uma janela preta com texto em branco (aqui é o Prompt de Comando)
Na parte inferior, você verá um cursor piscando
Digite exatamente: netsh winsock reset
Pressione a tecla Enter no seu teclado
Espere que diga "OK" ou termine o processamento
Passo 3: Digite o segundo comando

Digite exatamente: netsh int ip reset
Pressione a tecla Enter
Espera que acabe
Passo 4: Digite o terceiro comando

Digite exatamente: ipconfig / release
Pressione a tecla Enter
Espera que acabe
Passo 5: Digite o quarto comando

Digite exatamente: ipconfig / renew
Pressione a tecla Enter
Espera que acabe
Passo 6: Digite o quinto comando

Digite exatamente: ipconfig / flushdns
Pressione a tecla Enter
Espera que acabe
Passo 7: Fechar o Prompt de Comando

Clique no botão X no canto superior direito da janela Prompt de Comando
A janela irá fechar
Passo 8: Reinicie seu computador

Clique no botão START
Clique no ícone Poder (parece um círculo com uma linha no topo)
Clique em "Reiniciar"
Seu computador irá reiniciar
Esperar que ele arranque completamente
Teste a sua ligação à Internet
QUICK FIX # 6: Atualizar Drivers de Rede
Um driver é um software que ajuda o Windows a falar com o seu cartão Wi-Fi. Motoristas velhos podem causar problemas.

Passo 1: Abrir o Gerenciador de Dispositivos

Clique no botão START
Tipo: "manager de dispositivos"
Clique em "Device Manager" quando aparecer
Passo 2: Encontrar adaptadores de rede

Na janela Gerenciador de Dispositivos, você verá uma lista de dispositivos de hardware
Procure "adaptadores de rede" na lista
Clique na seta ao lado para expandi- la
Você verá seu adaptador de rede listado abaixo
Passo 3: Atualizar o driver

Botão direito do mouse em seu adaptador de rede (geralmente diz algo como "Intel Wireless" ou "Ethernet")
Um menu aparecerá
Clique em "Atualizar driver"
Passo 4: Deixe o Windows procurar por atualizações

Uma nova janela aparecerá perguntando como procurar por drivers
Clique em "Procurar automaticamente para software de driver atualizado"
Windows irá procurar por atualizações
Isto pode demorar alguns minutos.
Passo 5: Reinicie o seu computador

Depois que a atualização terminar, feche todas as janelas
Clique no botão START
Clique no ícone Energia
Clique em "Reiniciar"
Teste a sua ligação à Internet
Problema # 2: Internet é muito lento
FIX PRECISA # 1: Mova-se mais perto do seu roteador
Quanto mais longe estiveres do router, mais fraco é o sinal.

Encontre seu roteador (o dispositivo com antenas enviando Wi-Fi)
Mova seu computador mais perto dele
Remova quaisquer obstáculos entre seu computador e o roteador (paredes, objetos de metal, móveis grandes)
Teste sua velocidade de internet novamente
Acesse www.speedtest.net no seu navegador para testar sua velocidade
Fixação rápida #2: Verifique quantos dispositivos estão usando seu Wi-Fi
Muitos dispositivos usando Wi-Fi retardam sua conexão.

Veja outros dispositivos em sua casa (telefones, tablets, outros computadores)
Desligar Wi-Fi em dispositivos que não utiliza activamente
Se alguém estiver baixando arquivos grandes ou assistindo vídeos, peça-lhes para pausar
Teste sua velocidade de internet novamente
RÁPIDO FIX # 3: Reinicie seu roteador
Siga os mesmos passos que o QUICK FIX #3 acima (desligar por 30 segundos, voltar a ligar)
Espera que as luzes parem de piscar
Teste sua velocidade de internet
Quick FIX # 4: Tente uma rede Wi-Fi diferente
Muitos roteadores transmitem duas redes: 2,4 GHz (inferior, maior alcance) e 5 GHz (mais rápido, menor alcance)

Clique no ícone Wi-Fi no canto inferior direito
Veja as suas redes disponíveis
Se você ver duas redes com nomes semelhantes (pode-se dizer "5G" no final), tente a que você não está usando atualmente
Clique na outra rede
Digite sua senha
Teste a sua velocidade
QUICK FIX #5: Posicione seu roteador melhor
Certifique-se de que seu roteador não está em um armário ou espaço fechado
Coloque-a mais acima (em uma prateleira, não no chão)
Mantenha-o longe de objetos de metal (caixas, prateleiras de metal)
Mantenha-o longe de microondas e telefones sem fio (interfere com Wi-Fi)
Mantenha-o numa área aberta para um melhor sinal
Teste sua velocidade novamente
SECÇÃO 2: ALTERAÇÃO DO SEU ENDEREÇO PÚBLICA DE PI
O que é um endereço IP público?
Pense no seu endereço IP como o seu endereço de casa. Cada dispositivo na internet tem um. Sites podem ver seu endereço IP quando você os visita.

Um endereço IP público se parece com este: 192.168.1.1

MÉTODO 1: Reiniciar o seu modem (método mais fácil)
Esta é a maneira mais fácil. Funciona para a maioria das pessoas com internet em casa.

Passo 1: Encontre o seu modem

Procure o dispositivo com luzes piscando que seu cabo de internet conecta
Este é o seu modem
Passo 2: Desligue o cabo de alimentação

Encontrar o cabo de alimentação ligado ao modem
Siga-o até ao soquete da parede
Puxe suavemente a tomada da parede
Todas as luzes no modem desligarão
Passo 3: Espere 5 minutos

Não conectá- lo ainda
Aguarde 5 minutos completos (contagem: 60 segundos × 5)
Isto é importante - dá ao modem tempo para reiniciar completamente
Passo 4: Conecte de volta em

Empurre o plugue de energia de volta para a tomada de parede
As luzes voltarão a ligar
Espere 2-3 minutos para todas as luzes pararem de piscar
Isto significa que o modem foi reiniciado
Passo 5: Verifique seu novo endereço IP

Abra o seu navegador (Chrome, Firefox, Edge)
Ir para: www.whatismyipaddress.com
Você verá seu endereço IP público exibido na tela
Escreva para que possa comparar com o que era antes.
Se os números são diferentes, seu endereço IP mudou!
MÉTODO 2: Liberar e renovar o endereço IP do Windows
Este é um método alternativo que às vezes funciona.

Passo 1: Abrir Prompt de Comando

Clique no botão START
Tipo: "prompt de comando"
Botão direito do mouse em "Prompt de Comando"
Clique em "Execute como administrador"
Clique em "Sim" se solicitado para permissão
Passo 2: Libere seu endereço IP atual

Na janela Prompt de Comando, digite exatamente: ipconfig / release
Pressione a tecla Enter
Aguarde que ele seja concluído (você pode ver algum texto aparecer)
Passo 3: Espere 10 segundos

Não faças nada durante 10 segundos.
Espera.
Passo 4: Renovar o seu endereço IP

Digite exatamente: ipconfig / renew
Pressione a tecla Enter
Esperar que ele termine
Passo 5: Fechar o Prompt de Comando

Clique no botão X no canto superior direito
A janela irá fechar
Passo 6: Verifique seu novo endereço IP

Abra seu navegador web
Ir para: www.whatismyipaddress.com
Veja se o seu endereço IP é diferente
MÉTODO 3: Usar uma VPN (Rede privada virtual)
Uma VPN faz com que sites achem que você está em um local diferente com um endereço IP diferente.

Passo 1: Escolha uma VPN

Existem muitos serviços VPN disponíveis
Populares: NordVPN, ExpressVPN, ProtonVPN, Surfshark
Opção gratuita: ProtonVPN tem uma versão gratuita
Opções pagas: normalmente custam $5-15 por mês
Passo 2: Baixe a VPN

Abra seu navegador web
Pesquisar pelo nome VPN (por exemplo: "nordvpn.com")
Ir para o seu site
Clique no botão "Download"
Um arquivo será baixado para o seu computador
Passo 3: Instale a VPN

Encontre o arquivo baixado (geralmente na sua pasta "Downloads")
Clique duas vezes sobre ele para abri-lo
Siga as instruções de instalação
Clique em "Instalar" quando perguntado
Esperar que a instalação termine
Clique em "Terminar"
Passo 4: Abra a VPN

Clique no botão START
Procure o nome do aplicativo VPN em seus programas
Clique nele para abri-lo
Você pode precisar criar uma conta (assinar-se)
Passo 5: Conecte-se a um servidor VPN

No aplicativo VPN, procure um botão "Conectar" ou uma lista de países
Clique em "Conectar" ou selecione um país
A aplicação irá conectá- lo a um servidor VPN
Aguarde alguns segundos para a conexão estabelecer
Passo 6: Verifique seu novo endereço IP

Abra seu navegador web
Ir para: www.whatismyipaddress.com
Seu endereço IP deve agora ser diferente (ele mostrará a localização do servidor VPN ao qual você se conectou)
MÉTODO 4: Entre em contato com seu provedor de serviços de Internet
Se você precisar de um novo endereço IP permanente, você pode pedir à sua empresa de internet para lhe dar um.

Passo 1: Encontre o número de telefone do seu ISP

Veja a sua conta de internet
Encontre o número de telefone para o seu provedor de serviços de internet
Ou procure on-line "[Seu nome ISP] serviço ao cliente"
Passo 2: Chame-os

Ligue para o número de telefone
Aguarde por um representante de atendimento ao cliente
Diga-lhes: "Gostaria que me atribuisse um novo endereço IP público"
Eles normalmente fazem isso para você imediatamente.
Passo 3: Reinicie o seu modem

O representante poderá dizer- lhe para reiniciar o seu modem
Siga os passos do método 1 acima
Passo 4: Verifique seu novo endereço IP

Ir para www.whatismyipaddress.com
Seu IP deve ser diferente
SECÇÃO 3: PROBLEMAS PRINCÍPIOS
Problema # 1: A Impressora Não Imprime
Fixar rapidamente # 1: Reinicie a sua impressora
Passo 1: Desligue a impressora

Olhe para sua impressora
Encontrar o botão Energia (geralmente na frente ou lado)
Pressione-o para desligar a impressora
As luzes apagarão
Passo 2: Desligue o cabo de alimentação

Encontrar o cabo de alimentação ligado à impressora
Siga-o até ao soquete da parede
Puxe suavemente a ficha de alimentação da tomada de parede
Passo 3: Espere 30 segundos

Conte devagar, um mil, dois mil, trinta mil.
Passo 4: Conecte de volta em

Empurre o plugue de energia de volta para a tomada de parede
Passo 5: Ligue a impressora

Pressione o botão Energia para ligar a impressora
Aguarde que ele inicie completamente (luzes pararão de piscar)
Passo 6: Tente imprimir

Abra um documento ou foto em seu computador
Clique no menu Arquivo
Clique em Imprimir
Clique no botão Imprimir
Veja se a impressora imprime
Fixação rápida #2: Verificar conexões físicas
Para impressoras com fio (USB):

Passo 1: Verifique o cabo USB

Encontre o cabo USB que conecta sua impressora ao seu computador
Siga-o da impressora para o computador
Certifique-se de que ambas as extremidades estão firmemente ligadas
Se estiver solto, empurre-o suavemente até estalar.
Passo 2: Tente uma porta USB diferente

Desligue o cabo USB do seu computador
Olhe para o seu computador para outras portas USB (eles parecem pequenos buracos retangulares)
A maioria dos computadores tem várias portas USB
Conecte o cabo USB em uma porta diferente
Espere 10 segundos.
Tente imprimir novamente
Para impressoras sem fio:

Passo 1: Certifique-se de que a impressora está ligada

Olhe para sua impressora
Certifique-se de que está ligado (luzes devem estar acesas ou piscando)
Se desligado, pressione o botão Energia
Passo 2: Verifique se o Wi-Fi da impressora está ligado

Olhe para sua impressora para um botão Wi-Fi (geralmente mostra o símbolo Wi-Fi)
Pressione se estiver disponível
Procure uma luz Wi-Fi na impressora
Se estiver ligado, deve ser iluminado (geralmente azul ou verde)
Se estiver desligado, carregue no botão Wi-Fi para o ligar.
Passo 3: Certifique-se de que seu computador e impressora estão na mesma rede Wi-Fi

Clique no ícone Wi-Fi no canto inferior direito da tela
Veja o nome da sua rede
Na sua impressora, veja a tela de exibição ou documentação
Certifique-se de que a impressora está conectada à mesma rede que seu computador
Caso contrário, use os botões ou tela da impressora para selecionar a rede correta
Fixa rápida # 3: Verifique se há Jams de Papel e tinta baixa
Passo 1: Abra todas as capas e painéis

Olhe para sua impressora
Abra todas as portas, tampa e painel que você pode ver
Procura qualquer papel preso.
Se vir papel, retire-o suavemente (tenha cuidado para não o rasgar)
Passo 2: Verificar os níveis de tinta ou toner

Olhe para sua impressora
Deve haver um cartucho de tinta ou toner visível
Verificar se o nível de tinta está baixo
Se for baixo, terá de substituir o cartucho por um novo
(Pergunte a um membro da família ou amigo se precisar de ajuda com isto)
Passo 3: Verifique bandeja de papel

Olhe para a bandeja de papel (onde você carrega papel)
Certifique-se de que há papel carregado na bandeja
Se vazio, adicione papel (normalmente papel branco de 8,5" x 11")
Passo 4: Fechar todos os painéis

Fecha todas as portas e painéis que abriste
Certifique-se de que tudo estala
Passo 5: Tente imprimir novamente

Abrir um documento
Clique em Arquivo > Imprimir
Clique no botão Imprimir
Vê se imprime.
Fixação rápida #4: Remova e reinstale sua impressora

Passo 1: Abrir configurações

Clique no ícone de engrenagem para abrir Configurações
Passo 2: Vá para Bluetooth & Dispositivos

Na janela Configurações, olhe para o lado esquerdo
Clique em "Bluetooth & dispositivos" ou "Dispositivos"
Passo 3: Clique em Impressoras e scanners

No lado esquerdo, você deve ver "Printers & scanners"
Clique nele
Passo 4: Encontre sua impressora

No lado direito, você verá uma lista de impressoras
Procure sua impressora na lista
Clique nele para selecioná-lo
Passo 5: Remova a impressora

Deve aparecer um botão "Remover"

Fixar rapidamente # 3: Verifica a tua RAM
RAM é a memória do seu computador. A RAM falha muitas vezes causa telas azuis.

ATENÇÃO: Isto envolve abrir o seu computador. Se não te sentes confortável a fazer isto, pede ajuda a alguém.

Use uma chave de fenda para remover estes parafusos

Agora você pode ver dentro de seu computador
Passo 4: Encontrar a RAM

Olhe dentro do seu computador
RAM parece uma vara longa e fina com chips.
É geralmente perto da CPU (o grande chip quadrado no meio)
Os paus da RAM levantam-se verticalmente
Passo 5: Remover a RAM

Olha para as duas extremidades do stick RAM
Há pequenos clipes (como pequenas alavancas) em cada extremidade
Empurre estes clipes para baixo (ou para os lados) para desbloquear a RAM
A RAM vai aparecer ligeiramente
Puxe suavemente a RAM para fora
Coloque-o cuidadosamente numa superfície limpa
Passo 6: reinserir a RAM

Pega no stick RAM

FIX RÁPIDO # 4: Verificar o Sobreaquecimento
O superaquecimento causa quebras e telas azuis.

Passo 1: Sinta o ar saindo

Olhe para trás ou lado do seu computador
Deve haver aberturas (aberturas onde o ar sai)
Sinta o ar saindo com a mão
Se estiver muito quente, seu computador pode estar superaquecendo.
Passo 2: Verifique se há aberturas bloqueadas

Olha para todas as saídas do teu computador.
Certifique-se de que eles não estão bloqueados por poeira, papéis ou objetos
Se estiverem bloqueados, retirem cuidadosamente a obstrução.
Passo 3: Limpar filtros de poeira

Muitos computadores têm filtros de poeira
Estes são geralmente telas de malha nas aberturas
Procure acúmulo de poeira
Se muito empoeirado, use ar comprimido para soprar o pó para fora
Spray em rajadas curtas - não segure
Passo 4: Verificar o fluxo de ar

Certifique-se de que seu computador está em uma boa localização:
Não em um armário fechado (precisa de circulação de ar)
Não em uma superfície macia como uma cama (blocos de ventilação)
Em uma área aberta com bom fluxo de ar
Se em uma má localização, movê-lo para um lugar melhor
Passo 5: Verifique os ventiladores

Olhe dentro do seu computador (se você estiver confortável abrindo-o)
Você deve ver ventiladores (peças girando)
Certifique-se de que eles estão girando livremente
Se um ventilador está bloqueado ou não girando, você pode precisar de um profissional para ajudar
Passo 6: Reiniciar e testar

Feche o seu computador
Liga-o.
Use-o normalmente
Veja se o ecrã azul ainda acontece
